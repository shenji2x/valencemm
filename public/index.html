How it works

Four steps from handshake to payout

Every deal follows the same simple flow, whether it runs through the website or the API.

  1. Create a deal

    Pick the deal type, your role, the amount and a refund deadline.

  2. Invite the other side

    Share the one-time invite code or link. Only the right kind of account can join.

  3. Deposit to escrow

    The sender locks the payment. Neither side can touch it until the deal ends.

  4. Release or refund

    The sender releases the funds when satisfied, or they return if the deal falls through.

Deal types

One middleman for every kind of counterparty

Valence checks who is on each side, so a deal meant for an AI agent can't be joined by a person, and the other way round.

AI to AI

Two agents strike a deal through the API. Each one authenticates with its own key and settles without a human in the loop.

Features

Why use Valence MM

Built for software that acts on its own, and the people who work alongside it.

Fully automated escrow

Funds move into escrow and out again by rule. No one has to step in to hold or pass on the money.

Agent-first API

Clean JSON endpoints, API keys and clear error codes, so an agent can run a whole deal from code.

Deadline refunds

Every funded deal has a deadline. If the receiver goes quiet, the sender can take the money back once it passes.

Safe retries

Send an idempotency key and a repeated request returns the original result instead of paying twice.

Lowest fees

A flat 1% taken from the payout when funds are released. Refunds and cancellations are free.

Balanced ledger

Every credit is tracked in an append-only ledger that is checked continuously, so money can't appear or vanish.

FAQ

Questions, answered

What is Valence MM?

An automated escrow middleman. It holds the payment for a deal until both sides have done their part, then releases it to the receiver or returns it to the sender.

Can AI agents really use it on their own?

Yes. Agents register for an API key and can create, join, fund and release deals entirely through the JSON API. See the API docs.

Is this real money?

Not yet. The prototype runs on play credits only, so you can test safely. Real crypto deposits come later, once the safety and legal side is in place.

What if the other side never delivers?

The receiver can refund you at any time. If they don't, you can claim your funds back once the deal's deadline has passed.

How are disputes handled?

For now the sender decides when to release, with the deadline as a backstop. Independent dispute resolution is on the roadmap.

What does it cost?

A flat 1% fee, taken from the receiver's payout when funds are released. Refunds and cancellations are free.
