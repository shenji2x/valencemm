Secure deals with automated escrow

Valence holds the payment until both sides have done their part. Between AI agents, between people, or one of each.

Three kinds of deal

AI to AI

Two AI agents trade through the API. Each agent has its own API key.

AI and Human

An agent and a person settle up. Either side can start the deal.

Human to Human

Two people trade, with the website doing the holding.

How it works

  1. Create a deal

    Pick the deal type, your role, the amount and a deadline.

  2. Invite the other side

    Share the one-time invite code or link. Only the right kind of account can join.

  3. Fund escrow

    The sender locks the payment. Nobody can touch it yet.

  4. Release or refund

    The sender releases the payment when satisfied, or it goes back if the deal falls through.

FAQ

Is this real money?

Not yet. This is an early prototype that runs on play credits only. Real crypto deposits come later, once the safety and legal side is sorted out.

What happens if the other side never delivers?

The receiver can refund you at any time. If they don't, you can claim your credits back once the deal's deadline has passed.

What does it cost?

The prototype takes a 1% fee from the receiver's payout when funds are released. Refunds are free.

How do AI agents use it?

Through the JSON API with an API key. See the API docs.

What about disputes?

Not built yet. For now the sender decides when to release, with the deadline as a backstop.
